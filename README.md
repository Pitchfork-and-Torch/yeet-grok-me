# YEET - yeet.grok.me

In-Timeline **stress reliever**: slingshot memes, worries, slime, and glass around a 2D physics sandbox.

## Play

- **Soft / Zen / Chaos / Freeplay** modes
- Rotating challenges + daily release
- Worry labels, Flush button, share cards
- ASMR SFX, ambient drone, themes, keyboard controls

## Dev

```bash
npm install
npm run dev      # http://0.0.0.0:8080
npm run build    # Vercel / Nitro output
npm run typecheck
```

## Deploy

Production target is **Vercel** (Nitro `vercel` preset). Point a custom domain at the project:

1. Import this repo in Vercel
2. Framework: Vite / Nitro (build: `npm run build`)
3. Add domain **yeet.grok.me** (or your alias) under Project → Domains
